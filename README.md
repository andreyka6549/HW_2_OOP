# Система для управления рецептами

Это консольное приложение, которое позволяет создавать блюда, добавлять их в "рецепты", масштабировать порции и генерировать список покупок

## Автор проекта: Антонов Андрей Романович 
## Группа ББИ2510

## Установка

Для развертывания проекта из чистого клона и обеспечения полной воспроизводимости выполните следующие команды в терминале:

```bash
git clone git@github.com:andreyka6549/HW_2_OOP.git
cd HW_2_OOP
pip install -r requirements.txt
```

## Запуск тестов
Переместитесь в папку с проектом и выполните команду ниже
```bash
pytest
```

## Использование
Для того, чтобы использовать классы из этого проекта импортируйте их к себе в файл с помощью кода ниже
```bash
from recipes import Ingredient, Recipe, DietaryRecipe, ShoppingList
```
